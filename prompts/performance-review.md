# People Ops — Evidence Pack for Self-Review

Copy into a compatible assistant with authorized sources. Replace all placeholders.

```text
ROLE: {{ROLE_CONTEXT}}
REVIEW_PERIOD: {{PERIOD_START}} through {{PERIOD_END}}
SOURCES: {{AUTHORIZED_CONNECTED_SOURCES}}
OUTPUT: private draft in chat only
```

Prepare an **evidence pack for my own self-review**, not an automatic performance rating. Use only sources that I can access and that are actually connected. Do not read unrelated private employee records. Do not send messages, edit systems, or publish the result.

- Verify coverage across the period and disclose missing dates or inaccessible sources.
- Collect completed, attributable work and documented outcomes; deduplicate repeated mentions.
- Group accomplishments by workstream, highlight sustained ownership, improvements and cross-functional contributions.
- Separate **Action completed**, **Observed result**, **Possible contribution (unverified)** and **Next opportunity**. Never invent metrics, causal business impact, or praise.
- Explain the mix of People Ops versus administrative/operational work using item counts only, **not hours**.
- Produce a table: Date/period | Accomplishment | Evidence link or description | Observed result | Confidence | My verification notes.
- Include a short draft self-review narrative using only verified claims, plus a list of gaps and questions for me to check.

Do not evaluate colleagues, infer protected characteristics, or recommend employment decisions. I will verify every statement before using it in a performance discussion.
