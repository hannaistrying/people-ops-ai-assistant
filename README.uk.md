# People Ops AI Assistant 🌿

Практичний набір промптів та інструкцій, щоб створити **власного AI-асистента для People Ops** без програмування.

Асистент допомагає збирати підтверджені результати роботи, розуміти бізнес-контекст, аналізувати розподіл задач, пояснювати галузеві терміни, помічати можливі прогалини в HR-документації та готувати доказову базу для самооцінки.

## З чого почати

1. Прочитайте [покрокову інструкцію англійською](GETTING_STARTED.md).
2. Підключіть **лише дозволені компанією** та доступні вам джерела (наприклад, Slack, Gmail, Notion, Granola).
3. Оберіть [Notion-промпт](prompts/notion-ongoing.md) або [HTML-промпт](prompts/html-daily.md). За потреби скористайтеся [офлайн-конфігуратором](setup.html).
4. Замініть усі `{{PLACEHOLDER}}` на власні дані, запустіть промпт і перевірте факти перед збереженням результату.

## Інші сценарії

- [Тижневий / місячний підсумок](prompts/period-summary.md)
- [Доказова база для performance review](prompts/performance-review.md)
- [Приклад HTML Daily Brief](examples/daily-brief-demo.html) — **вигадані, синтетичні дані**, не реальний звіт із компанії.
- [Налаштування](CUSTOMIZATION.md) та [перевірка якості](docs/quality-checklist.md)

Це промпти, а не готова автоматично запущена система. Доступність конекторів і можливість запису до Notion залежать від інструмента та прав доступу. Ніколи не завантажуйте у публічний GitHub дані працівників, внутрішні документи або приватні посилання.
