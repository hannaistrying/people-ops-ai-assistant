# Upload this repository

1. Keep the GitHub repository **Private** until you have checked all content for confidentiality.
2. Download the ZIP and unzip it on your computer.
3. Open your empty GitHub repository, choose **uploading an existing file** (or Add file → Upload files).
4. Upload the **contents** of `people-ops-ai-assistant/`, preserving subfolders; do not upload the ZIP itself as your repository's only file.
5. Commit the changes, open the README and test the links.
6. Review prompts and screenshots again before switching visibility to Public.

This kit does not contain the article. The HTML example is explicitly synthetic.
